## Key Files Explained

- **pyproject.toml**: Project metadata and all required dependencies.
- **uv.lock**: Lockfile for reproducible dependency installs (auto-generated by uv).
- **.env**: Database URL and other environment variables (not committed to git).
- **app/main.py**: FastAPI app entrypoint; sets up logging, middleware, routers, events, health checks.
- **app/api/v1/api.py**: Main API router for version 1 endpoints.
- **app/core/config.py**: Loads settings from environment and .env.
- **app/core/exception_handlers.py**: Centralized exception handling for FastAPI.
- **app/db/base.py**: SQLAlchemy base model definition.
- **app/db/session.py**: Database session and engine setup.
- **app/db/models/**: SQLAlchemy ORM models (e.g., user model) for each resource/table.
- **app/db/schemas/**: Pydantic schemas for request/response validation.
- **app/db/crud/**: CRUD logic for each resource (e.g., user CRUD).
- **app/services/**: Business logic, e.g., user management.
- **alembic/**: Alembic migration setup and migration scripts.
- **tests/**: Test code, organized to mirror the app structure.

from sqlalchemy.future import select
from app.db.models.user import User

async def get_users(db):
    result = await db.execute(select(User))

async def create_user(db, name, email):

### `app/services/base_service.py` — Generic Base Service
```python
from typing import Type, TypeVar, Generic, Optional, List, Any, Dict
from sqlalchemy.ext.asyncio import AsyncSession
from sqlalchemy.future import select

ModelType = TypeVar("ModelType")

class BaseService(Generic[ModelType]):
    def __init__(self, model: Type[ModelType]):
        self.model = model

    async def find(self, db: AsyncSession, filters: Optional[Dict[str, Any]] = None) -> List[ModelType]:
        stmt = select(self.model)
        if filters:
            for key, value in filters.items():
                stmt = stmt.where(getattr(self.model, key) == value)
        result = await db.execute(stmt)
        return result.scalars().all()
```

### `app/services/user_service.py` — User Service Logic
```python
from app.services.base_service import BaseService
from app.db.models.user import User

class UserService(BaseService[User]):
    def __init__(self):
        super().__init__(User)

    async def get_by_username_or_email(self, db, identifier):
        from sqlalchemy.future import select
        result = await db.execute(select(User).where((User.email == identifier) | (User.username == identifier)))
        return result.scalars().first()
```

## Step-by-Step Setup

This section provides a highly detailed, reproducible guide to set up a new FastAPI project using `uv` as the package manager. It covers both using this boilerplate and creating a minimal FastAPI project from scratch.

### 1. Install uv (Dependency Manager)
Install `uv` globally if you haven't already:
```bash
pip install uv
# or (on Mac)
brew install astral-sh/uv/uv
```

### 2. Clone the Repository (or Start Fresh)
To use this boilerplate:
```bash
git clone <your-repo-url>
cd fastAPI_PostGres
```
Or, to create a new project from scratch:
```bash
mkdir my-fastapi-project
cd my-fastapi-project
uv init
```
This creates a starter `pyproject.toml` and `.python-version` file.

### 3. Add FastAPI and Uvicorn to Your Project
```bash
uv pip install fastapi uvicorn
```
This will update your `pyproject.toml` and lock dependencies in `uv.lock`.

### 4. Create a Minimal FastAPI App
Create a file named `main.py`:
```python
from fastapi import FastAPI
app = FastAPI()

@app.get("/")
def read_root():
    return {"message": "Hello, FastAPI!"}
```

### 5. Set Up Environment Variables
Create a `.env` file for local settings (for database, secrets, etc.):
```env
DATABASE_URL=postgresql+asyncpg://<user>:<password>@<host>:<port>/<database>
SECRET_KEY=your-secret-key
```
*Note: Use `python-dotenv` to load these automatically in your app.*

### 6. Set Python Version
Ensure `.python-version` exists (e.g., `3.13`). You can create it manually:
```bash
echo "3.13" > .python-version
```

### 7. Install All Project Dependencies
If using this boilerplate:
```bash
uv sync
```
If you added new dependencies, run:
```bash
uv pip install <package-name>
uv sync
```

### 8. Run the Application
For a minimal app:
```bash
uv run -- uvicorn main:app --reload
```
For this boilerplate (with modular structure):
```bash
uv run -- uvicorn app.main:app --reload
```

### 9. Database Migrations (If Using Alembic)
Run migrations to set up your database schema:
```bash
uv run -- alembic upgrade head
```

### 10. Add More Features
- Add routers/endpoints in `app/api/`
- Add models/schemas in `app/db/models/` and `app/db/schemas/`
- Add services/business logic in `app/services/`
- Add tests in `tests/`

## Development Workflow
- Use `uv run` for all commands to ensure correct environment.
- Add new dependencies to `pyproject.toml` and run `uv sync`.
- Write new API endpoints under `app/api/v1/endpoints/` and register them in `api.py`.
- Use Alembic for DB migrations: `uv run -- alembic revision --autogenerate -m "message"`.
- Add tests in the `tests/` directory, mirroring the app structure.
